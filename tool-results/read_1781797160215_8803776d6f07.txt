     1→     1→# Astrofeet — Worklog
     2→     2→
     3→     3→## Project Overview
     4→     4→Rebuild of Astrofeet (premium sneaker e-commerce, cosmic/neon theme) as a modern
     5→     5→Next.js 16 + TypeScript + Tailwind 4 + shadcn/ui full-stack app. Single user-facing
     6→     6→route `/` renders a client-side multi-view SPA. Backend = Next.js API routes
     7→     7→backed by a JSON-file mini-Prisma store (`src/lib/db.ts`) so the app runs with
     8→     8→zero external DB binaries. Swappable to real Prisma later (same API shape).
     9→     9→
    10→    10→## Architecture (established)
    11→    11→- **Views (SPA)**: `useUIStore` (src/stores/ui.ts) holds `view` + `params` and
    12→    12→  `navigate(view, params)`. `src/app/page.tsx` renders the active view.
    13→    13→  Views: home | products | product | checkout | order-success | admin.
    14→    14→- **Cart**: `useCartStore` (src/stores/cart.ts, persisted) — `items`, `add(product, size, qty)`,
    15→    15→  `setQuantity`, `remove`, `subtotal()`, `count()`, `open/close/toggle`.
    16→    16→- **Auth**: `useAuthStore` (src/stores/auth.ts, persisted) — `user`, `setUser`, `logout`, `isAdmin()`.
    17→    17→  Session = httpOnly cookie `astrofeet_session` (HMAC token). `api.me()` syncs on load.
    18→    18→- **API client**: `src/lib/client.ts` exports `api` with methods: `me, login, register, logout,
    19→    19→  products(params), product(slug), createProduct, updateProduct, deleteProduct, createOrder,
    20→    20→  listOrders, updateOrderStatus, createReview, adminMetrics, chat`.
    21→    21→- **Backend routes** (all under `src/app/api/*`, runtime=nodejs):
    22→    22→  - `auth/login|register|me|logout` (POST each; me=GET)
    23→    23→  - `products` (GET list w/ filters: category,brand,q,sort,min,max,size,featured,bestSeller; POST admin)
    24→    24→  - `products/[id]` (GET, PUT admin, DELETE admin) — id accepts slug OR id
    25→    25→  - `orders` (GET list — admin sees all, customer sees own; POST create — backend recalculates prices/shipping/total)
    26→    26→  - `orders/[id]/status` (PATCH admin) — statuses: created|paid|shipped|delivered|cancelled
    27→    27→  - `reviews` (GET ?productId=, POST)
    28→    28→  - `admin/metrics` (GET admin) — ordersToday, revenue, ticket, totalOrders, totalProducts, recent[], byStatus{}
    29→    29→  - `chat` (POST) — AI assistant via z-ai-web-dev-sdk LLM, system prompt = "Nave" support agent
    30→    30→- **Auth helpers** (src/lib/auth.ts): `getCurrentUser()`, `requireAdmin()` (throws AuthError w/ status),
    31→    31→  `setSessionCookie`, `clearSessionCookie`. Passwords hashed via scrypt (src/lib/crypto.ts).
    32→    32→- **Serialization** (src/lib/serialize.ts): `serializeProduct`, `serializeReview`, `serializeOrder`
    33→    33→  convert DB records (JSON string fields for images/sizes/items) to clean public types.
    34→    34→- **Types** (src/lib/types.ts): Product, Review, CartItem, Order, OrderLineItem, OrderStatus,
    35→    35→  PublicUser, ViewName, ViewParams.
    36→    36→- **Format** (src/lib/format.ts): `formatPrice`, `formatDate`, `maskCEP/Phone/Card/Expiry/CVV`,
    37→    37→  `orderStatusLabel`, `orderStatusColor`.
    38→    38→
